# 中药快快记答题程序（C# MAUI版）

一款基于.NET MAUI框架开发的中药知识答题应用，旨在帮助中医药学习者通过答题形式快速记忆中药功效、性味归经等核心知识点，题库内容均源自化学工业出版社出版的《中药功效快快记忆法》一书，兼具实用性与专业性。

![应用截图](screenshot.png)

## 一、功能特点
1. **权威题库支撑**：核心题库严格对标《中药功效快快记忆法》，覆盖常用中药的功效、主治、记忆口诀等关键知识点，贴合中医药学习备考需求；
2. **灵活答题模式**：支持随机答题模式，可自定义答题数量、知识点范围，避免机械刷题，提升记忆效率；
3. **学习数据追踪**：内置答题统计功能，自动记录错题、正确率、答题时长等数据，生成学习进度报表，清晰掌握自身薄弱点；
4. **现代化交互体验**：采用MAUI原生UI组件设计，界面简洁直观，操作流畅，适配不同设备的交互习惯；
5. **全平台适配**：基于.NET MAUI的跨平台特性，完美支持Android、iOS、Windows系统，可在手机、平板、电脑等设备无缝使用。

## 三、构建与运行指南
### 3.1 前置要求
- 操作系统：Windows 10/11（推荐）、macOS（需适配MAUI iOS开发环境）；
- 开发工具：Visual Studio 2026及以上版本（需安装MAUI开发工作负载）；
- 运行环境：.NET 10 SDK（[官方下载地址](https://dotnet.microsoft.com/download/dotnet/10.0)）；
- 额外依赖：Android SDK（如需编译Android版本）、Windows SDK 10.0.19041.0（如需编译Windows版本）。

### 3.2 仓库操作
```bash
# 克隆远程仓库到本地
git clone https://github.com/Pac-Dessert1436/ZhongYaoQuickMemo-MauiApp.git

# 切换到项目根目录
cd ZhongYaoQuickMemo-MauiApp
```

### 3.3 项目构建
```bash
# 恢复项目所有NuGet依赖包
dotnet restore

# 编译Android Release版本（适用于发布）
dotnet build -f net10.0-android -c Release

# 编译Windows Release版本
dotnet build -f net10.0-windows10.0.19041.0 -c Release

# （可选）本地调试运行（默认启动Windows版本，可在VS中切换平台）
dotnet run -f net10.0-windows10.0.19041.0 -c Debug
```

### 3.4 部署说明
- Android：编译完成后，在`bin/Release/net10.0-android/`目录下获取APK文件，可直接安装到安卓设备；
- Windows：编译完成后，在`bin/Release/net10.0-windows10.0.19041.0/`目录下获取可执行文件，或通过MSIX打包部署。

## 四、个人开发心得
这个项目的开发背景其实很特殊——它是我去年二战备考期间挤时间完成的。那段时间明明知道备考是首要任务，我到头来还是忍不住一头扎进编程代码里，现在回想起来，既有“耽误”备考的愧疚，也有在压力中找到出口的庆幸。

### 4.1 初衷与坚持
备考的日子枯燥且焦虑，而我本身又热爱编程，加上自己也是中医药专业的学习者，便想着做一款能贴合备考需求的答题工具：既可以把零散的学习时间利用起来，也能通过编程缓解备考的压力。于是每天挤2-3小时，从题库整理、框架选型到界面开发，一点点把想法落地。选择.NET MAUI也是看中了它的跨平台特性，一次开发能适配多端，不用为不同系统重复造轮子，节省了备考期间宝贵的时间。

### 4.2 框架升级的思考
近期对项目进行了框架版本的更新，现已迁移到.NET 10 MAUI，一方面是为了适配最新的开发工具和系统特性，提升应用性能；另一方面也是复盘当初的代码：备考时赶进度写的代码难免有不规范、疏漏的地方，这次升级也借机重构了核心逻辑，优化了答题数据存储、UI交互等模块，让应用更稳定、易用。

### 4.3 一点感悟
这段“备考+开发”的经历让我明白，兴趣和主业其实可以相辅相成：开发这款工具的过程，也是我对中药知识点反复梳理、记忆的过程，答题功能的设计思路，反而让我对考点的理解更深刻。当然也走了不少弯路——比如为了赶进度忽略代码规范，后期重构时花费了更多时间；平衡备考和开发的时间分配也一度让我焦虑。但最终看到自己写的工具能实实在在帮到自己（甚至身边的同学），所有的付出都变得有意义。

**对我而言，这个项目不只是一个技术实践作品，更是一段特殊时期的印记：它记录了我备战考研的焦虑，也见证了在压力下依然不愿放弃热爱的自己。后续我也会按需维护这款app，希望能帮到更多中医药学习者。**
